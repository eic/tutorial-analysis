## Glossary

EIC
:   Electron-Ion Collider

EICrecon
:   The EIC reconstruction software framework, whose output ROOT trees are analyzed in this lesson.

EDM4eic / EDM4hep
:   The event data models describing the branches stored in the reconstruction output trees.

PODIO
:   The Plain Old Data I/O library underlying the EIC event data model.
